# Forex Risk Manager

Mobile-first Next.js website for forex session risk management and position sizing.

## Run locally
npm install
npm run dev

## Deploy
Push the project to GitHub, import the repository into Vercel, then Deploy. No environment variables are required for this version.

## Risk model
The first release uses a simplified pip-value model for a USD-denominated account. Verify your broker's contract specifications and pip value before live trading. This tool does not provide entry signals or guarantee profits.
